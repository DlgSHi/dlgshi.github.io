Veilio

Two-way code anonymizer for AI tools and coding agents. It swaps real identifiers for placeholders before code reaches an LLM (UserAuthService.validateSessionToken → __CLS__1.__FN__2), then restores the real names in the answer, so your names stay on your machine. Ships as a Claude Code plugin, CLI, MCP server and web app; source-available.
